Frontend
| Tech/Library                 | Purpose                                                                 |
| ---------------------------- | ----------------------------------------------------------------------- |
| **Next.js 15**               | React-based framework with support for SSR/ISR, API routes, and routing |
| **React 19**                 | Core UI library                                                         |
| **Tailwind CSS 4**           | Utility-first CSS framework for styling                                 |
| **MUI (Material UI) 7**      | Component library for building accessible, consistent UI                |
| **TanStack Query 5**         | Data fetching, caching, and synchronization for React apps              |
| **React Hook Form**          | Form management with validation                                         |
| **Zod**                      | Schema validation (used with RHF)                                       |
| **Lucide React**             | Icon library                                                            |
| **React Calendar**           | Calendar UI component                                                   |
| **React Hot Toast / Sonner** | Notifications and toasts                                                |
| **Axios**                    | HTTP client for making API calls                                        |
| **js-cookie**                | Handling cookies (e.g., storing JWTs)                                   |

Backend
| Tech/Library             | Purpose                                    |
| ------------------------ | ------------------------------------------ |
| **Node.js**              | JavaScript runtime                         |
| **Express 5**            | Web server framework                       |
| **MongoDB (Mongoose 8)** | ODM for MongoDB and schema validation      |
| **JWT (jsonwebtoken)**   | Authentication using JSON Web Tokens       |
| **bcrypt**               | Password hashing                           |
| **dotenv**               | Manage environment variables               |
| **Helmet**               | Set secure HTTP headers                    |
| **CORS**                 | Enable Cross-Origin Resource Sharing       |
| **Morgan**               | HTTP request logging middleware            |
| **Multer**               | Handling file uploads                      |
| **Swagger (UI & JSDoc)** | Auto-generated API documentation           |
| **Nodemon**              | Auto-restarting dev server on file changes |
